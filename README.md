# Welcome to the Stormlight Archive Archive

This project displays interactive visualizations for *The Way of Kings* and *Words of Radiance* by Brandon Sanderson. Please see the about page for more information.

## Running the site

The live site can be accessed [here](https://tsaa.onrender.com/).

To run the website locally, first clone the repository, then make sure you're in the root directory and call
`pip install -r requirements.txt`
to install necessary dependencies. Then, run
`python app.py` to start the server.
